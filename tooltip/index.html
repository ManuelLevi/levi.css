Tooltip

A short note on hover or keyboard focus. Put it in data-tooltip; no JavaScript. It only supplements: what the user needs to read must also be on screen. A control without text needs an aria-label too, and a plain element needs tabindex="0" to be reached by keyboard.

3 waiting Documentation
