Date range

Two native date fields in one pill. It keeps the height of every other row, so it sits on the same line as tabs, a toolbar or a title.

Show code 
<div class="mc-daterange" role="group" aria-label="Date range">
  <label>From <input type="date" value="2026-10-01"></label>
  <label>To <input type="date" value="2026-10-31"></label>
</div>
