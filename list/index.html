List with values

A data at the end of an item puts its value on the right. data-status colors it. For lines between the rows, use a table.

  1. Invoice approval412 runs
  2. Onboarding88 runs
  3. Expense report3 failed
Show code 
<ol class="mc-list">
  <li><a href="#">Invoice approval</a><data value="412">412 runs</data></li>
  <li><a href="#">Onboarding</a><data value="88">88 runs</data></li>
  <li><a href="#">Expense report</a><data value="3" data-status="danger">3 failed</data></li>
</ol>

Action in a list

A button in a list takes the same row as a link. It suits an action in a sidebar: New, Create.

  • Workflows
  • Runs
Show code 
<ul class="mc-list">
  <li><button type="button">New workflow</button></li>
  <li><a href="#">Workflows</a></li>
  <li><a href="#">Runs</a></li>
</ul>
