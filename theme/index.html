Theme

Two colors ship with Levi: navy, the primary, and emerald, the secondary. Add mc-emerald to mc-theme, or to any container, to make emerald the primary and navy the secondary. Everything else is a variable.

Navy

A link in the primary

Emerald

A link in the primary

Show code 
<body class="mc-theme mc-emerald">

.mc-theme{
  --mc-primary: rebeccapurple;
}

Light and dark

Both come from the same tokens and follow the system on their own. Force either one with a class.

mc-light

mc-dark

Muted text

For secondary text. It takes the muted color, and nothing else.

Invoice approval updated 3 hours ago

Show code 
<p>Invoice approval <span class="mc-muted">updated 3 hours ago</span></p>

Visually hidden

Text for screen readers only, such as a label for a column or a control that has none on screen.

Show code 
<button class="mc-button"><span class="mc-visually-hidden">Delete </span>x</button>
