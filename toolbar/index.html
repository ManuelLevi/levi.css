Toolbar

A menu of controls in one row. A search field takes the room that is left.

    •
    Show code 
    <menu class="mc-toolbar">
  <li><input class="mc-input" type="search" placeholder="Search" aria-label="Search"></li>
  <li><button class="mc-button">Filter</button></li>
  <li><button class="mc-button mc-primary">New</button></li>
</menu>

    A form in one row

    For a form that fits on one line, put a toolbar inside it. Labels, fields and the button share the row.

    •
    Show code 
    <form>
  <menu class="mc-toolbar">
    <li><label>Name <input class="mc-input" type="text" placeholder="New workspace"></label></li>
    <li><button class="mc-button mc-primary">Create</button></li>
  </menu>
</form>
