Icon

An SVG from icons.svg, drawn in the text color at the text size. The set is Lucide (ISC license), one stroke for all. Next to the text in a list or sidebar item it takes its own space, and in a collapsed sidebar only the icon stays. A pill or a value goes at the end of the item, in a data.
