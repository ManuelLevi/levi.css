Color

Every color is a variable on mc-theme, with one value for light and one for dark. The ratio is each color against the page background of its own mode.

Light

Surfaces and text

  • --mc-bg#fff
  • --mc-surface#f5f5f7
  • --mc-raised#fff
  • --mc-border#d9d9de
  • --mc-text#1d1d1f16.83:1
  • --mc-muted#6e6e735.07:1
  • --mc-hover#0000000d
  • --mc-shadow#00000026

Status

One word on the element, data-status, and the dot, the text or the number takes the color.

  • --mc-ok ok#1a7f375.08:1
  • --mc-warn warn#c750004.59:1
  • --mc-danger danger#c628285.62:1
  • --mc-muted muted#6e6e735.07:1

Accent

Crimson by default. mc-navy and mc-emerald on the theme swap it.

  • --mc-accent crimson#dc143c4.99:1
  • --mc-accent mc-navy#1e3a8a10.36:1
  • --mc-accent mc-emerald#0478575.48:1
